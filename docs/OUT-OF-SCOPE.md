# Out of scope (v1)

Do not implement these unless the owner expands scope explicitly.

- ATS / single-column job-board export
- Cover letters, LinkedIn optimization, interview prep
- Multi-user accounts, auth, cloud sync
- Multiple named CV variants / per-job forks
- Playwright (or other) one-click headless PDF download
- Production deploy (Vercel, Netlify, GitHub Pages)
- Pixel-perfect recreation of a third party’s PDF chrome
- Committing real private contact details into `cv.public.json`
